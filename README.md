# Viva

A voice-first study companion. Add your notes, Viva turns them into flashcards, then quizzes you out loud, grades your spoken answers, and schedules reviews with spaced repetition.

Built for the Alexa+ track of the Build, Ship, Shape: Amazon Developer Hackathon 2026. Viva is both a real MCP server and a simulated Alexa+ experience in the browser that calls that same server.

> Work in progress. Setup, architecture and deploy instructions are filled in as each part lands.
